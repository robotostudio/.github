# Roboto Studio

We're a headless website agency. We build with Sanity, Next.js, Shopify, and Contentful, and we open source our starters.

## Starter templates

- [turbo-start-sanity](https://github.com/robotostudio/turbo-start-sanity) is a Sanity + Next.js page builder template with visual editing ([demo](https://sanity.robotostudio.com))
- [turbo-start-contentful](https://github.com/robotostudio/turbo-start-contentful) is a Contentful + Next.js starter template ([demo](https://contentful.robotostudio.com))
- [turbo-start-shopify](https://github.com/robotostudio/turbo-start-shopify) is a headless Shopify starter with Sanity and Next.js ([demo](https://turbo-start-shopify-web.vercel.app))
- [hotrod](https://github.com/robotostudio/hotrod) is an agent-first Astro website starter for sites maintained by coding agents ([demo](https://hotrod.robotostudio.com))

More about us at [robotostudio.com](https://robotostudio.com).
